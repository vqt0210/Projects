# Projects

Tổng hợp các project nhỏ được xây dựng để thực hành, chủ yếu học theo tutorial trên YouTube — mỗi project tập trung luyện 1 kỹ năng hoặc công nghệ cụ thể.

## Danh sách project

### [MovieTime](./MovieTime)
Website đặt vé xem phim — React, Node.js, Express, MongoDB. Thực hành quy trình phát triển full-stack: xem phim, chọn ghế, thanh toán trực tuyến, xuất vé kèm mã QR.

### [Color-Palete-Generator](./Color-Palete-Generator)
Công cụ tạo bảng màu ngẫu nhiên — thực hành JavaScript cơ bản, thao tác DOM và xử lý sự kiện.

### [DigitalClock](./DigitalClock)
Đồng hồ điện tử hiển thị thời gian thực — thực hành JavaScript với `Date`, cập nhật giao diện theo thời gian thực.

### [Quiz-Game](./Quiz-Game)
Trò chơi trắc nghiệm nhỏ — thực hành xử lý logic, state và tương tác người dùng bằng JavaScript.

## Mục đích

Repo này dùng để lưu lại quá trình tự học lập trình web thông qua việc làm theo các tutorial thực tế, từ đó làm quen dần với cú pháp, cấu trúc project, và cách một ứng dụng web vận hành từ giao diện đến xử lý dữ liệu.

## Công nghệ đã tiếp xúc qua các project trong repo

- JavaScript, React
- Node.js, Express
- MongoDB
- HTML/CSS

## Ghi chú

Đây là các project thực hành cá nhân, không phải sản phẩm hoàn chỉnh dùng trong môi trường thực tế. Một số project (như MovieTime) có tích hợp thêm tính năng nâng cao đang được tiếp tục tìm hiểu sâu hơn.
